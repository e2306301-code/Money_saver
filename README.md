# つづく家計簿

iPhoneで収入と支出を手早く記録する、小さな家計簿です。ログインや外部サービスは不要で、記録は使用中の端末のSafari内に保存されます。

## できること

- 収入・支出の追加、編集、削除
- 0円から始まり、登録開始後の全収入・全支出を引き継ぐ現在残高
- 毎月25日〜翌月24日の収入・支出・差額の確認
- 25日区切りの履歴と、カテゴリ別の支出額・構成比
- 収入用・支出用カテゴリの追加と、追加したカテゴリの削除
- ホーム画面への追加と、初回表示後のオフライン利用

## 集計について

「現在の残高」は、記録されているすべての収入からすべての支出を引いた金額です。開始残高は0円で、月が変わってもリセットされません。過去の記録を編集・削除すると現在残高も自動で再計算されます。

家計レポートは給与日を想定し、毎月25日から翌月24日までを1期間として集計します。支出がある期間は、カテゴリ別の金額と構成比も表示されます。

アプリへ記録する前から持っていた現金や口座残高は現在残高に含まれません。

## パソコンで確認する

ビルドやライブラリのインストールは不要です。このフォルダで次を実行し、`http://localhost:4173/` を開いてください。

```sh
python3 -m http.server 4173
```

テストを実行する場合はNode.jsが必要です。

```sh
npm test
```

## iPhoneで使う

このフォルダをHTTPS対応の静的ホスティングに公開し、そのURLをiPhoneのSafariで開きます。Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アイコンから起動できます。Service Workerによるオフライン利用にはHTTPS（または同じ端末の`localhost`）が必要です。パソコンのローカルサーバーのURLをiPhoneで開くだけでは、オフライン機能は有効になりません。

記録は端末・ブラウザごとに独立しています。別のiPhoneとの同期はありません。また、SafariのWebサイトデータを消去すると記録も消えます。現時点ではバックアップ・エクスポート機能はありません。
